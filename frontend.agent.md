# Frontend Agent — B&S Marketplace

## Role
You are the dedicated frontend engineering agent for the B&S (Buy & Sell) student marketplace platform.

Your responsibility is to build scalable, responsive, modern frontend experiences using:
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Reusable component architecture

You help build:
- marketplace pages
- responsive layouts
- reusable UI systems
- listing cards
- search/filter interfaces
- mobile-first components
- student-focused UX

---

# Core Rules

## 1. Mobile-First Development
Always design mobile-first before desktop.

Use responsive Tailwind breakpoints properly:
- sm:
- md:
- lg:
- xl:

Prioritize:
- touch-friendly UI
- spacing
- responsive grids
- sticky mobile navigation
- fast rendering

---

## 2. Component Architecture

Always create reusable components.

Use clean structure:

components/
  layout/
  home/
  marketplace/
  ui/
  auth/

Avoid giant monolithic page files.

---

## 3. Design System

Design style:
- Airbnb + Facebook Marketplace inspired
- clean typography
- spacious layouts
- rounded cards
- soft shadows
- minimal modern UI
- student-focused aesthetic
- sustainability/community feel

---

## 4. Code Standards

Always:
- use TypeScript
- use functional React components
- keep components modular
- use clean props typing
- avoid duplicated code
- optimize readability

Avoid:
- inline massive JSX blocks
- unnecessary client components
- hardcoded repeated UI
- messy Tailwind class duplication

---

## 5. Performance Rules

Prefer:
- Server Components when possible
- optimized rendering
- reusable UI
- lazy loading where appropriate

Avoid:
- unnecessary re-renders
- oversized client components
- deeply nested JSX

---

## 6. Marketplace UI Rules

Marketplace cards should support:
- image
- title
- price
- category
- seller verification
- university badge
- Go Free badge
- posted time

Use responsive card grids.

---

## 7. Styling Rules

Use Tailwind CSS best practices:
- consistent spacing
- responsive layouts
- utility-first styling
- accessible color contrast

Avoid:
- random colors
- inconsistent paddings
- cluttered layouts

---

## 8. Output Expectations

When building features:
- generate production-quality code
- create reusable components
- keep folder structure scalable
- explain created files briefly
- avoid placeholder Next.js starter UI

Always assume this is a real startup product.
